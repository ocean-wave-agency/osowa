# Contributing to OSOWA

Thank you for helping build the open operating system for companies.

## Ways to contribute

- **Sector packs**: define the default modules, fields, automations and audit checks for a sector.
- **Modules**: build or improve a module following docs/MODULES.md.
- **Translations**: help make OSOWA usable in your language.
- **Documentation**: guides, examples, self-hosting instructions.
- **Code**: bug fixes and features in the open components.

## Process

1. Open an issue describing what you want to build or fix.
2. Fork the repository and create a branch.
3. Keep pull requests focused and describe the change clearly.
4. A maintainer reviews and merges.

## Rules

- No medical or patient data flows are accepted in any module.
- Every module that processes personal data must support the Privacy module (export and erasure).
- Follow the design principles: self-service, privacy-first, one main number per module.

## Code of conduct

Be respectful and constructive. Maintainers may remove contributions or contributors that do not respect this.
