# Roadmap

This roadmap describes the path from the current production platform to a fully open, community-driven operating system for companies.

## Phase 0: Foundation (Q4 2026)

- Public repository, license, contribution guidelines
- Module specification published (docs/MODULES.md)
- Architecture documentation (docs/ARCHITECTURE.md)
- Public roadmap and issue tracker

## Phase 1: Open core (Q1 2027)

- Release of the data model and entity schemas for all modules
- Release of the Audit engine: Digital and Legal Audit framework, scoring and action plan generator
- Release of the Privacy module (access log, retention, export, erasure)
- Sector definition format: how a sector declares its default modules, fields and automations
- First three sector packs: hospitality, real estate, professional services

## Phase 2: Community modules (Q2 2027)

- Module SDK so contributors can build and publish a module
- Translation framework, starting with English and Dutch
- Self-hosting guide (Docker) with a reference deployment
- Public demo environment with the fictional company Lumora Hotels & Spa

## Phase 3: AI layer (Q3 2027)

- Open AI agent framework per module with transparent usage tracking per company
- Pluggable model providers
- Audit to proposal pipeline fully open

## Phase 4: Worldwide (2028)

- Ten or more sector packs maintained by the community
- Localisation for ten or more languages
- Governance model and maintainers council
- Hosted edition by Ocean Wave Agency and independent hosting partners

Progress is tracked in GitHub issues and milestones.
